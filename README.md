# Pellow River Postcards — digitisation package

Digitisation package for the Pellow River Postcards (FMA-PRP-1902), released on 2026-06-12.

## Contents

- `manifests/box-list.csv` — box-level inventory for the 620 postcards
- `metadata/postcards.csv` — item metadata including publisher, series and postmark date
- `scripts/derivatives.py` — derivative generation settings used for the access copies
- `docs/rights-review.md` — rights review notes for the postcard publishers

## Access

Access derivatives are served from the catalogue; preservation TIFFs remain on the archive store. Cite the item identifier together with the postmark date where known.

## Version

Package version 2.0 — last content update 2026-06-12.
